# 判定ロジックのルール

- 判定（照合・利益・◎○×）は **2か所**にある: `yahoo_bid/bid_analyzer.py`（Python）と `yahoo_bid/userscript_template.js`（Chrome拡張機能）。
  片方を変えたら必ずもう片方も同じに直す。
- 変更後は `cd yahoo_bid && python3 -m unittest test_bid_analyzer` を実行（JSとPythonの一致テストを含む）。
- 誤判定を見つけたら、実例を `yahoo_bid/knowledge/データ/照合ルールと落とし穴.md` に追記してからルールを足す。
- 拡張機能を作り直すのは `python3 build_userscript.py --chrome`。ユーザーには chrome://extensions の ↻ を押すよう伝える。
