# 判定ロジックのルール

- 判定（照合・利益・◎○×）は **2か所**にある: `tools/appraise.py`（Python）と `tools/extension_template.js`（Chrome拡張機能）。
  片方を変えたら必ずもう片方も同じに直す。
  店舗アプリの `store/core.js` は拡張機能の `@core-start`〜`@core-end` を `python3 tools/build_store.py` でコピーしたもの（直接編集しない）。
- 変更後は `python3 -m unittest discover -s tools` を実行（JSとPythonの一致テストを含む）。
- 誤判定を見つけたら、実例を `knowledge/データ/照合ルールと落とし穴.md` に追記してからルールを足す。
- 拡張機能を作り直すのは `python3 tools/build_extension.py`。ユーザーには chrome://extensions の ↻ を押すよう伝える。
- 商品名の読み取り（型の語・F値・まとめ売りの中身・光学難など）を変えるときは、作る前に日本語の商品名のよくある書き方を自分で洗い出し、`tools/test_store.py` の `JapaneseTitlePatterns` に足してから直す（2026-11-18 ユーザー指示「この程度の指摘をさせない」）。最低限見る書き方:
  - F値とボディ: 「Nikon F2 ボディ」（型番）／「Nikkor 35 F2」「35mm F2」（F値）／f/2・f1.4・1:2
  - 焦点距離: 「５０ミリ」「50㎜」「50 mm」、ズーム「28-70mm」、フィルムの「35mm フィルムカメラ」「6x6判」は焦点距離ではない
  - 型番: 数字の無いボディ（SP・FM・RTS・XD）、ハイフン（AE-1・OM-1・X-T2・E-410・VH-510）、型番でない英字（AI・AF・ED・MC・FD）、ストアの管理番号（N031・Tj036・末尾の【9022NT】K11・【K172】K03・【1582-4NT】K17）。括弧の中の型番（【D750】【SX-70】）は消さない
  - 実際の出品で見つけた誤りは、その商品名をそのままテスト（`test_trust.py` の `StoreCodeTitles` など）に足してから直す（2026-11-19 ユーザー指摘）
  - シリーズ名（2026-11-19 監査）: 機種名に PowerShot（Power Shot・パワーショット）・IXY・EOS Kiss（Kiss だけでも EOS を補う）・COOLPIX・Cyber-shot・LUMIX・FinePix・PEN（PEN F・PEN EE・PEN-FT）・OM-D・mju（μ・ミュー）・ESPIO・XA（XA 2→XA2）・Nikon 1 を残す。比較用キーと相場の当たり方には使わない（`LINE_WORDS`）
  - 型番でない語（2026-11-19 監査）: #5344A2104・末尾の e7467・S/N・管◯◯・シャッター333回・2個まとめ・391g・3x（ズーム倍率）・PC1250（Canon の内部型番）・【20260103KNK-002】。大文字の「NIKON D850」「CANON 600D」は消さない。判（645・110）は残し、判違いのレンズは当てない（`TITLE_FIXES`・`format_of`）
  - 社外レンズ・書き間違い: 「ROKINON 35mm キャノンマウント」は Rokinon 製（社名がメーカー名より前のとき）。Cannon・OLIMPUS・OLYNPUS・NIKKON はメーカー名として読む。「non Ai」は非Ai
  - 区切り: ＋ + 、 , ／ / ・ ＆ と、区切り無しの並び（「F3 50mm F1.4 28mm F2.8」）
  - 打ち消し: 「カビ・クモリなし」「クモリ：無」
- 入札候補の並び（`bid_priority` / `bidPrio`）と勝ちやすさの表示（`win_label` / `winText`）も2か所にある。1割未満の機種を下に回す規則を変えたら両方を直し、`test_win_plan.py` の一致テストを通す。勝ちやすさは並び・表示だけに使い、判定・上限額の計算には入れない。
