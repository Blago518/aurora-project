# 判定ロジックのルール

- 判定（照合・利益・◎○×）は **2か所**にある: `tools/appraise.py`（Python）と `tools/extension_template.js`（Chrome拡張機能）。
  片方を変えたら必ずもう片方も同じに直す。
  店舗アプリの `store/core.js` は拡張機能の `@core-start`〜`@core-end` を `python3 tools/build_store.py` でコピーしたもの（直接編集しない）。
- 変更後は `python3 -m unittest discover -s tools` を実行（JSとPythonの一致テストを含む）。
- 誤判定を見つけたら、実例を `knowledge/データ/照合ルールと落とし穴.md` に追記してからルールを足す。
- 拡張機能を作り直すのは `python3 tools/build_extension.py`。ユーザーには chrome://extensions の ↻ を押すよう伝える。
- 商品名の読み取り（型の語・F値・まとめ売りの中身・光学難など）を変えるときは、作る前に日本語の商品名のよくある書き方を自分で洗い出し、`tools/test_store.py` の `JapaneseTitlePatterns` に足してから直す（2026-11-18 ユーザー指示「この程度の指摘をさせない」）。最低限見る書き方:
  - F値とボディ: 「Nikon F2 ボディ」（型番）／「Nikkor 35 F2」「35mm F2」（F値）／f/2・f1.4・1:2
  - 焦点距離: 「５０ミリ」「50㎜」「50 mm」、ズーム「28-70mm」、フィルムの「35mm フィルムカメラ」「6x6判」は焦点距離ではない
  - 型番: 数字の無いボディ（SP・FM・RTS・XD）、ハイフン（AE-1・OM-1・X-T2・E-410・VH-510）、型番でない英字（AI・AF・ED・MC・FD）、ストアの管理番号（N031・Tj036・末尾の【9022NT】K11・【K172】K03・【1582-4NT】K17）。括弧の中の型番（【D750】【SX-70】）は消さない
  - 実際の出品で見つけた誤りは、その商品名をそのままテスト（`test_trust.py` の `StoreCodeTitles` など）に足してから直す（2026-11-19 ユーザー指摘）
  - シリーズ名（2026-11-19 監査）: 機種名に PowerShot（Power Shot・パワーショット）・IXY・EOS Kiss（Kiss だけでも EOS を補う）・COOLPIX・Cyber-shot・LUMIX・FinePix・PEN（PEN F・PEN EE・PEN-FT）・OM-D・mju（μ・ミュー）・ESPIO・XA（XA 2→XA2）・Nikon 1 を残す。比較用キーと相場の当たり方には使わない（`LINE_WORDS`）
  - 型番でない語（2026-11-19 監査）: #5344A2104・末尾の e7467・S/N・管◯◯・シャッター333回・2個まとめ・391g・3x（ズーム倍率）・PC1250（Canon の内部型番）・【20260103KNK-002】。大文字の「NIKON D850」「CANON 600D」は消さない。判（645・110）は残し、判違いのレンズは当てない（`TITLE_FIXES`・`format_of`）
  - 社外レンズ・書き間違い: 「ROKINON 35mm キャノンマウント」は Rokinon 製（社名がメーカー名より前のとき）。Cannon・OLIMPUS・OLYNPUS・NIKKON はメーカー名として読む。「non Ai」は非Ai
  - 区切り: ＋ + 、 , ／ / ・ ＆ と、区切り無しの並び（「F3 50mm F1.4 28mm F2.8」）
  - 打ち消し: 「カビ・クモリなし」「クモリ：無」
- 入札候補の並び（`bid_priority` / `bidPrio`）と勝ちやすさの表示（`win_label` / `winText`）も2か所にある。1割未満の機種を下に回す規則を変えたら両方を直し、`test_win_plan.py` の一致テストを通す。勝ちやすさは並び・表示だけに使い、判定・上限額の計算には入れない。
- 即決の別枠（2026-11-20 予約リストの実例）: 箱だけ・ホットシューカバー・スクリーン・本（〜の使い方・日本カメラ社）・カメラバッグ・三脚座・補修用パーツ・バッテリーパック・フェイクが、高い本体の相場で「即決で買える」に並んでいた。これらは「付属品のみ?」にする（「〜付き」の本体は除く）。旧ソ連製（Industar・Jupiter・FED・Zorki・Helios）は社外品として Leica に当てない。即決価格が上限額の4割未満のものは即決の別枠に出さない（`INSTANT_MIN_RATIO` / 拡張機能の instant。判定は変えない）。テストは `test_realized.py` の `InstantLaneJunk`。
- 相場メモが2つ以上当たったとき（2026-11-20 ユーザー指摘「320ドルに直しても更新されない」）: 古い登録「Canon X10 $540」と新しく［直す］した「$320」の両方が当たり、真ん中の $430 で計算されていた。相場メモ（手で直した相場）は**いちばん新しい1つだけ**を使う（このブラウザで直したもの〈直した時刻 t〉＞ Mac の相場メモ〈日付〉）。`appraise.match_prefer_memo` / 拡張機能 `newestMemo`。テストは `test_realized.py` の `NewestMemoWins`。
- 紛らわしい兄弟の機種を eBay の検索から外す語（2026-11-22 オーナーが「Olympus ZUIKO AUTO-W 24mm F2」の Sold に自分で「-2.8」を足した）: 相場データに同じメーカー・同じ焦点距離で F値だけ違うレンズがあれば「-2.8」を Sold・Now の検索語の後ろに足す（小数の F値だけ。「-2」は広すぎる。最大3語）。**ボディの世代語（HP・Pro・Program など）は外さない**: ヤフオクの商品名は「F3」とだけ書いた HP、「RB67」とだけ書いた Pro S が普通にあり、外すと売れた記録まで消えて相場を低く読む。ボディで外す語を足すときは、何に何が付くかの一覧をオーナーに見せて選んでもらってから。表示・リンクだけで、照合・判定には使わない。`appraise.sibling_excludes` / 拡張機能・店舗アプリ `siblingExcludes`。テストは `test_appraise.py` の `SiblingExcludes`（Python と JS の一致も）。
- eBay の検索語は機種の語だけ（2026-11-22 オーナー「まだ sold や now 開くと管理番号が入ってる」「PC のヤフオク入札でも」）: 店舗アプリ・拡張機能・毎朝のレポートとも、メーカー＋機種（系統・世代・マウント・焦点距離・F値）だけにし、管理番号（E66・N031・e6）・状態・付属品の語を入れない。`build_store.model_query` / 拡張機能 `modelQuery`（決まりの正規表現は Python から渡す）/ 店舗アプリ `modelWords`。テストは `test_appraise.py` の `ModelQuery`（Python と JS の一致）と `test_store_flow.py`。
- 説明文の動作の不良（2026-11-23 オーナー決定「要確認にする」）: 出品ページの説明文に「回りません」「ピントが合いません」「不安定」「ヒビ」「リングが固い」「シャッターが切れません」「電源が入りません」などがあれば、◎○ から外して要確認にし、予約リストに載せない（× にはしない。光学難は今までどおり ×）。「ヒビ・割れはありません」のような打ち消しは除く（語そのものの「ない」は打ち消しと読まない）。「ジャンク」の表記だけでは拾わない。**露出計の不良（露出計が動きません・露出計不動・メーター動作未確認）は拾わない**（同日 オーナー「露出計不良はオッケー」。記載して出せば売れるので、仕入れの判定でも難としない。塗装の剥離・はがれも同じ。レンズ・コーティングの剥離は今までどおり拾う）。返品の決まり文句に出る「動作不良」は拾わない。二重の打ち消し（「クモリがないわけではない」「なくはない」）は「ある」と読む。`appraise.DEFECT_RE`・`is_negated` / 拡張機能 `DEFECT_RE`・`isNegated`。テストは `test_trust.py` の `Description`（実際の出品の文。Python と拡張機能の一致も）。新しい書き方を見つけたら、その文をそのままテストに足してから語を足す。
- 説明文のストアの決まり文句と打ち消し（2026-11-23 露出計不良の出品を実際に開いて見つけた。狙い目の出品が決まり文句のせいで × になっていた）: 「カビくもりの有無等の状態の程度の問題に関しては」「すれ・きず・くもり等の主観による過多など」「極小のカビや薄い曇りなど「無」と記載されていても見落としや…」「デートバックは…全て動作未確認です」は難として拾わない。打ち消しに「なく・無く」を足した（カビや曇りなくクリア）。「薄くもりのみで撮影には影響ない」の「影響ない・問題ない」は くもり の打ち消しではない（くもりあり）。判定の語を変えたら、**実際の出品ページを何件か開いて通す**（作った文だけで確かめない）。テストは `test_trust.py` の `Description`。
- 全部チタン外装の機種（2026-11-25 オーナー決定「T2 は語で分けない」）: 限定・チタン・ゴールドは片方にだけあれば相場を当てない（`PREMIUM_VARIANTS`）が、CONTAX T2 は銀も黒もチタンなので「チタン」「Titanium」の語では分けない（同じ銀の T2 に相場が当たっていなかった。ヤフオクの落札でも語の有無で差は無かった）。ゴールド・限定は今までどおり別物。色（黒・銀）では分けていない。`appraise.ALL_TITANIUM`・`premium_of` / 拡張機能 `premOf`。テストは `test_appraise.py` の `AllTitanium`（Python と JS の一致も）。
