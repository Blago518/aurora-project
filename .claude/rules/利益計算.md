# 利益計算のルール

- **保守的に**計算する。迷ったら安い相場・高いコストを採る。赤字仕入れを防ぐことが最優先。
- 入札判断の基準: 利益3,000円以上 **かつ** 利益率10%以上（`tools/config.toml` の [judge]）。
- 送料は販売価格から一律 $40 を差し引く（入札判断。2026-11-15 に $30 から変更。今から仕入れる商品は次の出品から送料 $40 を乗せるため）。出品中・販売済みの商品の見積もり（数字のグラフ）は $30（`listed_deduction_usd`）。eBay手数料: FVF実効12%＋海外1.45%＋広告2.2%＋$0.44。円転ロス2%。消費税還付は含めない。
- ジャンク表記は想定販売価格を7割で見る。光学難（カビ・クモリ・バルサム）は要確認（修理しない方針）。
- 根拠の強さを必ず示す: 自分の販売実績 ＞ Chatwork実績 ＞ 頒布会リスト（出品価格で成約額ではない）＞ 鑑定表(推定)。
- 数値を変えたら `config.toml` を直し、`knowledge/意思決定ログ.md` に日付付きで記録する。
