# 利益計算のルール

- **保守的に**計算する。迷ったら安い相場・高いコストを採る。赤字仕入れを防ぐことが最優先。
- 入札判断の基準: 利益2,500円以上 **かつ** 利益率（売上＝eBay売値の円換算に対する割合）10%以上で**全体統一**（2026-11-16 ユーザー決定。安心ストアなどの例外なし。`tools/config.toml` の [judge]）。
- ジャンク表記は気にしない（届くまで分からないため）。割り引かず、ジャンクという理由だけでは要確認にしない。
- eBay 出品中の最安値から相場を出すとき: **送料無料の出品は出品額 − $30**、送料を別に取っている出品は出品額（商品代）そのままを、送料別の商品代として提示する。sold（売れた価格）も同じく、送料無料で売れたものは売れた額 − $30（2026-11-16 ユーザー決定。`active_free_ship_deduction_usd`。仮の相場は最安値）。
- 送料は販売価格から一律 $40 を差し引く（入札判断。2026-11-15 に $30 から変更。今から仕入れる商品は次の出品から送料 $40 を乗せるため）。出品中・販売済みの商品の見積もり（数字のグラフ）は $30（`listed_deduction_usd`）。eBay手数料: FVF実効12%＋海外1.55%＋広告2.2%＋$0.44。円転ロス2%。消費税還付は含めない。
- eBay の$は**送料を除いた商品代（net・送料別）**で表示・入力する（2026-11-15 ユーザー指定。拡張機能・スマホのアプリ・毎朝のレポート）。相場データ（price_memo.csv など）と計算は送料込みのまま持ち、入力された net には送料 $40 を足して保存する。
- ジャンク表記も想定販売価格は割り引かない（2026-11-16 ユーザー指定で7割評価をやめた。`junk_price_factor = 1.0`）。説明文や商品名にはっきり書かれた光学難（カビ・クモリ・バルサム）は要確認（修理しない方針）。
- 根拠の強さを必ず示す: 自分の販売実績 ＞ Chatwork実績 ＞ 頒布会リスト（出品価格で成約額ではない）＞ 鑑定表(推定)。
- 数値を変えたら `config.toml` を直し、`knowledge/意思決定ログ.md` に日付付きで記録する。クラウドからは古物台帳（Claude更新版）の「意思決定ログ」シート（日付・決めたこと）に書けば、毎朝の `update_all.py` が Mac の md に追記する。
