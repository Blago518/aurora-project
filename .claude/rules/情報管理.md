# 情報管理のルール（最重要）

- GitHub リポジトリ `aurora-project` は**公開**。
- 次は**絶対にコミットしない**: `data/`（仕入値・販売実績）、`knowledge/`（事業ナレッジ・目標・実績）、`reports/`（レポート）、`extension/`（相場データ入りの拡張機能）。いずれも .gitignore 済み。
- `.claude/` と CLAUDE.md は公開される。ここには氏名・取引先の個人名・金額の実績・口座・スプレッドシートIDなどを書かない（事業の中身は knowledge/ に書く）。
- コミット前に `git status` と `git diff --cached` で、上記が含まれていないか確認する。
- 外部サービス（Web検索など）に個人名・取引情報を送らない。

## 規約の順守
- **eBay のページ（検索結果・販売履歴・出品）をプログラムで自動取得しない。** スクレイピングは eBay の規約違反。 eBay の相場は、ユーザーが sold リンクや Product Research で確認した数字、自分の販売実績、Chatwork・頒布会のデータだけを使う。
- 他のサイトでも、自動取得の前に利用規約で許されているか確認し、分からなければユーザーに確認する。
