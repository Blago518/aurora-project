# 状態ランクの付け方（出品・古物台帳の状態欄）

2026-11-20 ユーザー決定: ランクは**講座のコンディション基準**に合わせる（同日、ピカチュウ案の厳しめの上限ランクから切り替え）。
基準の表（外観・レンズ光学・ファインダー光学・基本ルール）は講座資料なので公開リポジトリには写さない。中身は非公開の
`knowledge/講座/コンディション基準_外観`・`_レンズ光学`・`_ファインダー`・`_基本ルール`（古物台帳「共有_ナレッジ」から毎朝入る）を見る。

## 1. ランクの書き方（8つ。上から順に良い）
Unused ／ TOP MINT ／ MINT ／ Almost MINT ／ Near MINT ／ Exc+5 ／ Exc+4 ／ As-Is（講座の表に出る Exc+3 も使ってよい）

- **OptMINT（Opt MINT）も使う**（2026-11-23 オーナー「optmintなんだから、外観は傷ありでもいいのよ」）。光学（レンズ・ファインダー）が MINT で、外観には傷があってよい物に付ける。「全体はいちばん低いところに合わせる」の例外で、オーナーが状態欄に OptMINT と書いた物は、外観の傷を理由に Near MINT や Exc+5 に置き換えない。説明文には外観の傷を事実どおり書く。
- 略し方はやめる: NM・NMINT・NearMINT → Near MINT、E5・Ex5・Ex+5 → Exc+5、TopMINT・Top MINT → TOP MINT、Mint → MINT、AMINT・AlmostMINT → Almost MINT。「+++」などの上乗せ記号は使わない。
- 並び順は `tools/appraise.py` の `COND_RANK`（拡張機能の `RANK_LABEL`）と同じ。

## 2. 決め方（自分の言葉での要約）
- 外観・レンズ光学・ファインダー光学を、それぞれ講座の表で決める。大きさ（mm）・数・広がり（%）・見え方（対面がどれだけ見えるか）で小・中・大に分ける。
- 全体のランクは、いちばん低いところに合わせる。
- 同じくらいの軽い症状がいくつか重なっても、それぞれが Near MINT 程度なら全体も Near MINT でよい。
- 高く売れそうなときは、1段上げてもよい（2026-11-20 ユーザー決定「使う」）。**その場合も説明文の症状は必ず書く。**
- ファインダーはレンズより甘めに付く（写りに出ないため）。

## 3. 説明文に必ず書くこと（返品を防ぐ。2026-11-20 ユーザー決定）
- ランクに関係なく、見つけた症状を **種類・場所・数** で事実どおり書く（例: 点カビ1つ（後玉）、薄いくもり（ファインダー））。
- カビ・くもり・バルサム切れがある物は、英語の商品名か説明に Fungus ／ Haze ／ Balsam を入れる（`情報管理.md`: 事実と違う説明は作らない）。
- 返品で戻った物は、返品理由の症状を書き足してランクを見直す。

## 4. 古物台帳の状態欄の書き方
`ランク/症状・程度(数)(場所)` を「、」で並べる。場所は 前玉・中玉・後玉・ファインダー・外観 のどれかを必ず書く。

例: `Near MINT/点カビ1(後玉)、薄くもり(ファインダー)、キズ少し(外観)`

- 症状の語は くもり／カビ／蜘蛛カビ／点カビ／バルサム切れ／キズ／チリ／ゴミ／黄変／汚れ／塗装はがれ／ベタつき にそろえる。
- 機能は確かめた項目を書く（例: 動作確認: シャッター全速・絞り・露出計）。付属品も書く。

## 5. 仕入れの判定とは別
- 拡張機能・入札リストの判定（商品名・説明文にカビ・クモリがはっきり書かれた出品は ×）は、このランクの付け方とは別の決まり（`利益計算.md`）で、変えない。
