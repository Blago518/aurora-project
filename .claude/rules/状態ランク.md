# 状態ランクの付け方（出品・古物台帳の状態欄）

2026-11-20 ユーザー決定（ピカチュウ案＋ユーザーの選択）。返品・返金を減らすため、ランクの書き方と、欠点があるときの上限をそろえる。

## 1. ランクは次の8つだけ（上から順に良い）
Unused ／ TOP MINT ／ MINT ／ Almost MINT ／ Near MINT ／ Exc+5 ／ Exc+4 ／ As-Is

- 略し方はやめる: NM・NMINT・NearMINT → Near MINT、E5・Ex5・Ex+5 → Exc+5、TopMINT・Top MINT → TOP MINT、Mint → MINT、AMINT・AlmostMINT → Almost MINT。
- 「+++」などの上乗せ記号は使わない。
- 並び順は `tools/appraise.py` の `COND_RANK`（拡張機能の `RANK_LABEL`）と同じ。

## 2. ランクの基準（外観・光学・機能のうち、いちばん悪い所で決める）
| ランク | 外観 | 光学 | 機能 |
|---|---|---|---|
| TOP MINT | 使用感がほぼ無い | 欠点なし（ごく小さいチリまで） | 全項目を確認済みで問題なし |
| MINT | わずかな使用感 | チリ少しまで | 問題なし |
| Almost MINT | MINT と Near MINT の間 | チリ少し〜やや多め | 問題なし |
| Near MINT | 小キズ・使用感あり | チリ多め、写りに出ない細い拭きキズまで | 問題なし |
| Exc+5 | 目立つキズ・塗装はがれ | 点カビ少数、薄いくもり、キズ | 軽い難（鳴きなど）まで |
| Exc+4 | 傷み多い | カビ多い・蜘蛛カビ・くもり・バルサム切れ | 一部に不具合 |
| As-Is | ― | 重い光学難 | 動作しない・未確認 |

## 3. 欠点があるときの上限ランク
| 欠点 | 付けてよい一番上のランク |
|---|---|
| チリ少し | MINT |
| チリ多い／細い拭きキズ／外観の小キズ | Near MINT |
| 点カビ（少数）／薄いくもり／レンズのキズ／ファインダーのカビ・くもり／塗装はがれ／鳴き | Exc+5 |
| 蜘蛛カビ／カビ多い／くもり（薄くない）／バルサム切れ／キズ多数 | Exc+4 |
| 動作不良・動作未確認 | As-Is |

- カビ・くもり・バルサム切れがある物は、英語の商品名にも Fungus ／ Haze ／ Balsam を入れる（説明文は事実どおり。`情報管理.md`）。
- 返品で戻った物は、返品理由の欠点を書き足し、1段下げて出し直す。
- ランクを下げたときの出品価格はユーザーが決める。

## 4. 状態欄の書き方
`ランク/欠点・程度(数)(場所)` を「、」で並べる。場所は 前玉・中玉・後玉・ファインダー・外観 のどれかを必ず書く。

例: `Exc+5/点カビ4(後玉)、薄くもり(後玉)、キズ少し(外観)`

- 欠点の語は くもり／カビ／蜘蛛カビ／バルサム切れ／キズ／チリ／黄変／汚れ にそろえる（曇り・クモリ・ちり・傷 などを混ぜない）。
- 「(F)」「(レンズ)」だけ、「傷」だけの書き方はしない（場所が分からず、出品の状態表が「要確認」になる）。
- 機能は確かめた項目を書く（例: 動作確認: シャッター全速・絞り・露出計）。付属品も書く。
