# 講座資料・本・動画の取り込み

1. 内容を読み、要点を短くまとめる。宣伝・勧誘の部分は外す。今の体制と照らし、「導入済み／一部／未導入」を表にする。
2. 取り入れる候補を出し、**選択式の質問画面**でユーザーに選んでもらう。仕入れ・お金・顧客に関わる変更（判定や上限額など）は必ず確認してから。
3. 要点は古物台帳「共有_ナレッジ」シート（ファイル名・本文）に書く → 翌朝 Mac の `knowledge/講座/` に入る。出典（資料名・受け取った日）を本文の先頭に書く。
4. 公開リポジトリ（.claude/・tools/）には資料の文章を写さない。ルールや手順にするときは自分の言葉で短く（著作権のため）。
5. 店舗などで使う早見表が役立つなら Artifacts で作る（スマホで見やすく、ロゴや資料の画像は使わない）。
6. 決めたことは「意思決定ログ」シートに日付付きで残す。
