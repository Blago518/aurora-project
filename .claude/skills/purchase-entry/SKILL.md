# 仕入れの台帳入力

1. 元の情報を集める: 落札分ページ（PDF・スクショ・Claude in Chrome で読んだもの）や店舗のレシート。**台帳に書く値はすべて元の情報と1件ずつ照合し、根拠を示す**（確かめられない値は空欄にして「要確認」と書く）。
   - 商品名・落札/購入日・税込の支払額（商品代＋送料）・出品者名（アカウント名）・オークションID または店舗名。
2. 番号（No.）は台帳の最後の番号の続き。ユーザーの番号の付け方（アルファベット＋数字）に合わせ、決まっていなければ選択式の質問画面で聞く。勝手に新しい系列（Z など）を始めない。
3. 検品用の道具や備品は台帳に入れず「備品・経費」シートへ（2026-11-17 ユーザー決定）。
4. 書く場所は csv貼付（元の台帳）。**管理シートの数式の列には書かない**（上書きすると数式が消える）。キャンセル等の印は csv貼付の備考列。
5. 入庫担当（フシギダネ）に任せるときは、ユーザーが検品を終えたものだけ。台帳・お金に関わる提案は、ユーザーに出す前にマネージャー（サトシ）が中身を確認する。
6. ユーザーには「入れた行（No.・商品・支払額）→ 要確認の点」を表で伝える。

## 落札分ページを Claude in Chrome で読むとき（2026-11-17 ユーザー決定: 読むだけなら使う）
- 使うのは、ユーザーが頼んだときだけ（Mac の Claude アプリ・Chrome 拡張機能から）。定期実行や大量の読み込みはしない。
- 読むのは自分の「落札分」一覧（https://auctions.yahoo.co.jp/my/won）と、必要な商品ページだけ。ページ送りは必要な分だけ、ゆっくり。
- **入札・支払い・取引ナビへの入力・評価など、ボタンを押す操作は一切しない**（共通利用規約の「BOT 等による不正な操作」・細則の「過度な負荷」に当たらないように）。
- 他の利用者の個人情報（出品者の住所・氏名など）は集めない。台帳に必要なアカウント名・オークションID・金額だけ。
- 読み取った値も、上の手順どおり1件ずつ照合してから行を作る。
