# 入札候補の選定

1. ユーザーから検索URL（ヤフオクの検索結果・出品者ページ）を受け取る。複数可。
2. `data/search_urls.txt` に1行1本で保存する（いつもの検索URLは保存済み）。
3. 実行（aurora フォルダで）:
   ```bash
   python3 tools/appraise.py
   ```
4. `reports/bid_report_*.csv` から ◎○ を**終了が近い順**に取り出し、表にする:
   | 終了 | 商品（ヤフオクリンク） | 現在 | 上限入札額 | eBay相場（$→soldリンク） | 根拠 |
5. 根拠が「鑑定表(推定)」「リサーチ(推定)」「ジャンク」のものは、入札前に sold リンクで確認するよう注意書きを付ける。頒布会は講師陣が売れやすい物を選んだリストで、売れた記録と同じに扱う（確認不要。2026-11-18・22 オーナー）。
6. 相場が無い機種が多ければ、`reports/unpriced_models_*.csv` の上位を示し、`price-research` スキルを提案する。

注意: クラウド環境からは eBay に接続できない（403）。eBay の数字はリンクで示す。
