# 届いた後の検品（2026-11-20 ユーザー決定。フシギダネ案）

目的: 説明文に無い光学難・不具合を、出品者に返品を申し出られるうちに見つけること。出品の状態ランクを正しく付けること。

## 1. 届いた日（1件 15分）
1. 開封の様子と中身を写真に撮る。
2. 付属品と説明文を照らし合わせる（キャップ・フード・電池蓋・ストラップなど）。
3. 光学: LED ライトでレンズを透かし、カビ・くもり・バルサム切れ・キズを **種類＋場所（前玉・中玉・後玉・ファインダー）＋数** で記録し、透過写真を撮る（返品を申し出るときの証拠）。
4. **ここまで終わるまで、ヤフオク・店の受取連絡はしない**。

## 2. 出品者に返品・一部返金を申し出る目安
- 説明文に無い光学難（カビ・くもり・バルサム切れ）か機能不良があり、**かつ** 見込み売値の下がり幅が 5,000円以上、または仕入値の20%以上。
- ジャンク・現状品と書かれていた物、説明文に書いてあった欠点は申し出ない。
- 各ストアの返品の条件と期限は、商品ページで確かめる。申し出るか、どう伝えるかはユーザーが決める（Claude は連絡しない）。

## 3. 週末にまとめて（約2時間）
- 機構: シャッター全速・絞り・ピントリング・巻き上げ・露出計・AF。
- AF レンズとデジタルは、手元の試し撮り用ボディで写して確かめる。
- 試し撮り: 商品価格（送料別）が $300 以上の機械式・中判・レンジファインダーは、フィルム1本を試し撮りする。それより安い物は、古いフィルムで装填・巻き上げ・巻き戻しだけ確かめる。
- 清掃は外側だけ（外装・ゴム・接眼・前後玉の表面・接点）。ミラー・スクリーン・センサーはブロワーだけ。分解・修理はしない（光学難は直さない方針）。

## 3.5 直さずに「書いて出す」物（2026-11-23 オーナーが先輩の出品者から聞いた話。自分の販売実績ではまだ確かめていない）
- **露出計の不良**: 気にしない買い手が多い（絞りとシャッター速度で合わせる・別の露出計を使う）。直さず、説明文に「露出計は動かない」と事実どおり書いて出す。隠さない・「未確認」と書かない。
- **塗装はがれ**: 黒の補修ペンで塗ってから出してよい。**塗ったことを説明文に必ず書く**（例: Some paint loss on the edges has been touched up.）。つや消しの面にはつや消し、つやのある鏡筒にはつや有りを使い、目立たない所で試してから塗る。
- ランクは `.claude/rules/状態ランク.md` のとおり外観・機能で付ける（塗ったからといって上げない）。

## 4. 状態ランクと台帳
- ランクと状態欄の書き方は `.claude/rules/状態ランク.md` に従う。
- 例: `Exc+5/点カビ4(後玉)、薄くもり(後玉)、キズ少し(外観)`
- 説明文は事実どおりに書く（分かっている欠点を「未確認」と書かない）。
