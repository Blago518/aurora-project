# 輸出許可通知書を DHL・FedEx からもらう

2026-11-23 オーナー依頼「DHLとfedexから輸出許可証をもらわないといけない」「fedexのexcelはあなたが自動入力して作成するように」。
発送は CPaSS 経由（オークレボから）。**CPaSS 経由でも、輸出許可通知書の輸出者はオーナー本人**（2026-11-23 にもらった過去の FedEx 5通・DHL 4通で確かめた）。

## FedEx（公式サイトで申請 → 届いた Excel に番号を入れて返信）
1. 通関サービスセンターで「輸出許可通知書のリクエスト」を出す: https://www.fedex.com/ja-jp/customs-tools/clearance/customs-services.html
2. 受付メール「FedExJP:輸出許可通知書-リクエストシートのご案内」が届く（2026-11-23 に確かめた）。Excel「輸出許可通知書-リクエストシート」が付いている。
3. **Excel はプログラムが埋める**（Mac の aurora フォルダで）:
   ```bash
   python3 tools/export_permit.py ~/Downloads/<受付メールの Excel>.xlsx
   ```
   - CPaSS 注文一覧（data/statements/）から FedEx の運送状番号（12桁）を集め、**まだもらっていない物だけ**を B17〜（1〜200番）に入れる。B16 の見本は消さない。200件を超えたら 2つ目のファイルに分ける。
   - アカウント番号（9桁）は B13 の黄色の欄。`--account 123456789` で入れる。
   - 許可日から3年より前の物は入れない（FedEx が出せない）。
   - 保存先: `reports/fedex_export_permit_<日付>.xlsx`。
4. 受付メールに**返信**で、その Excel を添付して送る（件名・本文は変えない）。送り先は受付メールに書かれたアドレス（2026-11-23 の受付メールでは送信元とは別のアドレス。送信元は自動送信専用で返事が届かない）。
5. 2営業日で届く（20件超はもっと・100件超は2週間程度）。届く PDF の名前は「<運送状番号>_RELS_<日付>.pdf」。

## DHL（公式サイトのフォームから申請するだけ）
1. DHL の「輸出入関連書類送付リクエスト受付フォーム」から依頼する（運送状・インボイス・輸出入許可書をここで頼める）。案内: https://www.dhl.com/discover/ja-jp/contact-us
2. 依頼する運送状番号（10桁）の一覧はプログラムが出す:
   ```bash
   python3 tools/export_permit.py --dhl
   ```
   まだもらっていない物だけを表示し、`reports/dhl_export_permit_<日付>.txt` にも書く。フォームに貼る。
3. 請求書が出た荷物は DHL MyBill からもダウンロードできる。分からないとき: jpcqhandling@dhl.com・03-6732-4980（平日 9:00〜17:30）。
4. 届く PDF の名前は「<運送状番号10桁>.pdf」。
- 確かめていない: フォームの URL と入力する項目、1回に何件まで頼めるか、料金、届くまでの日数（オーナーが申請したときの画面で書き直す）。

## もらった物の扱い
- 届いた PDF はダウンロードフォルダに置いたままでよい。`export_permit.py` を動かすと `data/export_permits/` に写し（元は消さない）、もらった物として次の依頼から外す。
- 輸出の証拠として保存する（期間・税務の扱いは税理士に確かめる）。中身に購入者の名前・住所があるので、リポジトリには入れない（data/ はコミットしない）。

## まだ分からないこと
- CPaSS 注文一覧のどの列に FedEx・DHL の運送状番号が入っているか（実物で確かめる。見つからなければプログラムが列名を表示して止まる）。
- FedEx のリクエストシートに入れるアカウント番号（CPaSS 経由の出荷に使った番号）。
