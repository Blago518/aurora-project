# 月次の振り返り

1. 目標は `knowledge/CLAUDE.md` の「目標と実績」。
2. 古物台帳（スプレッドシートの「管理」の月次サマリーと「Mac_取引」「Mac_販売」。元の「ebay売上」は購入者の個人情報があるので読まない）から集計: 売上、利益、仕入額、販売件数、平均利益率、在庫日数（購入日→販売日）、返品・返金。
3. 目標との差と、月末までの1日あたり必要ペースを出す。
4. 良かった機種・仕入先、在庫日数が長い商品（タイトル見直しの候補。値下げは、オーナーに頼まれたときだけ案にする）を挙げる。
5. 次の1週間の打ち手を3つまで。結果を `knowledge/` に `振り返り/YYYY-MM.md` として保存し、[[00_ホーム]] からリンク。
