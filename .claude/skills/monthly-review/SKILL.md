# 月次の振り返り

1. 目標は `yahoo_bid/knowledge/CLAUDE.md` の「目標と実績」。
2. 古物台帳（スプレッドシートの「管理」「ebay売上」シート）から集計: 売上、利益、仕入額、販売件数、平均利益率、在庫日数（購入日→販売日）、返品・返金。
3. 目標との差と、月末までの1日あたり必要ペースを出す。
4. 良かった機種・仕入先、在庫日数が長い商品（値下げ・タイトル見直し候補）を挙げる。
5. 次の1週間の打ち手を3つまで。結果を `yahoo_bid/knowledge/` に `振り返り/YYYY-MM.md` として保存し、[[00_ホーム]] からリンク。
