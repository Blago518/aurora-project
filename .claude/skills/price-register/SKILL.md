# 相場の登録（クラウドから）

1. 登録する機種・相場$（**送料別の商品代**）・状態（MINT など。分からなければ空欄）をユーザーに確かめる。迷う点は選択式の質問画面で聞く。
   - 送料無料で売れた sold は −$30、送料別で売れたものはそのまま（.claude/rules/利益計算.md）。
   - 機種名は拡張機能の「機種」と同じ書き方（例: `Nikon Ai-S 50mm f/1.2`）。似た別機種と取り違えない。
2. 古物台帳「共有_相場メモ」シートの最後の行の下に、1機種1行で追記する（列: 機種・相場$（送料別）・状態・日付）。他の行は変えない。
3. 「相場候補」シートから来たものは、その行を変えずに残す（下調べの記録）。
4. 翌朝 Mac の `ledger_sync.py` が送料 $40 を足して `data/price_memo.csv` に入れる。前の値は相場の履歴（data/price_memo_history.csv）に残り、拡張機能の［履歴］で見られる。
5. ユーザーには「何を登録したか（機種・$・状態）→ 反映は明日の朝」を短く伝える。
