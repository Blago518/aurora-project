# .claude フォルダ

Claude Code が自動で読み込む設定。公開リポジトリに入るので、事業の数字や個人情報は書かない（それは knowledge/ へ）。

| フォルダ | 中身 | 使われ方 |
|---|---|---|
| `rules/` | 細かいルール（コミュニケーション・利益計算・情報管理・判定ロジック・カスタマー対応） | 毎回自動で読み込まれる |
| `skills/` | 手順書（入札候補の選定・相場調査・相場の登録・仕入れの台帳入力・講座資料の取り込み・データ更新・Chatwork取り込み・月次振り返り） | 依頼内容に合うものを Claude が自動で使う。`/bid-selection` のように名前でも呼べる |
| `agents/` | 担当者（入札担当・相場調査担当・出品改善担当・数字管理担当） | 「入札担当に任せて」のように頼むと、その担当が作業する |
| `hooks/` | 自動チェック（`guard_commit.py`: コミット・プッシュ前の公開チェックと、プログラムを含むコミット前のテスト、`run_tests.py`: tools/・store/ を直したらテスト） | `settings.json` に登録すると、Claude の操作の前後に自動で動く |
