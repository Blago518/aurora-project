Privacy Policy — Aurora

English

Aurora is a private, single-user tool that the seller uses to manage their own eBay business (their own orders, listings, fees and payouts). It is not offered to other users.

  • Data accessed: only the seller's own account data through the official eBay APIs (orders, listings, financial transactions), and public active-listing data through the eBay Browse API.
  • Buyer information: buyer names, addresses, user IDs, e-mail addresses and phone numbers are not stored. Only the destination country and order number are kept for bookkeeping.
  • Storage: data is stored only on the seller's own computer and the seller's own private spreadsheet. It is not sold, shared or disclosed to third parties.
  • Credentials: API keys and tokens are stored in the operating system's secure keychain on the seller's computer.
  • No scraping: eBay web pages are not scraped; only the official APIs are used.
  • Deletion: access can be revoked at any time from the eBay account settings, and stored data is deleted on request.

日本語

Aurora は、出品者本人が自分の eBay 事業（自分の注文・出品・手数料・入金）を管理するための個人用ツールです。他の利用者には提供していません。

  • 取得するデータ: eBay 公式 API による本人のアカウントのデータ（注文・出品・取引明細）と、Browse API による公開中の出品情報のみ。
  • 購入者の情報: 氏名・住所・ユーザーID・メールアドレス・電話番号は保存しません。帳簿のために配送先の国と注文番号のみ保持します。
  • 保存場所: 本人のコンピューターと本人の非公開スプレッドシートのみ。第三者への販売・共有・開示はしません。
  • 認証情報: API キーとトークンは本人のコンピューターのキーチェーンに保存します。
  • スクレイピングなし: eBay のページを自動取得せず、公式 API のみを使います。
  • 削除: eBay のアカウント設定からいつでも連携を解除でき、保存データは求めに応じて削除します。
